AI 樂齡學習教練・操作手冊

← 回到教練

這是什麼

給長輩的 AI 學習教練。一天學一件事，一課約 5 分鐘，總共 24 課：認識 AI、學會開口問、防詐保平安、健康、生活、家人與回憶。

不用註冊，不用登入，打開就能學。

畫面下方三個按鈕

  • 📅 今天學：看日曆上的今日一課，按「開始學」。
  • 💬 問教練：打字或用講的，也可以直接按常見問題。
  • 🛡️ 防詐騙：一鍵打 165、檢查可疑訊息、練習看穿騙術。

怎麼上一課

  1. 在「今天學」按「開始學」。
  2. 照順序看三步：聽教練說、動手試、答一題。
  3. 每頁都能按「🔊 唸給我聽」。
  4. 學完會蓋一個紅印章，再按「撕下今天的日曆」。

答錯不會扣分，也一樣拿得到印章。學過的課過幾天會出一題複習，在開始新課前自動跳出來。

想重看哪一課，按「我的印章」，再按那一課。

字太小、聲音太快

  • 右上角「放大字」按一下放大一級。
  • 「⚙ 常用設定」可以調字體大小、高對比畫面、朗讀速度、教練對您的稱呼。

加入主畫面

加入後就像 App 一樣，從手機桌面點開。

  • 安卓手機：按頁面下方「📲 加入主畫面」。沒有跳出視窗時，按瀏覽器右上角選單，選「加到主畫面」。
  • iPhone：用 Safari 打開，按「分享」圖示，選「加入主畫面」。

給家人與講師

  • 第一次請陪長輩走完第一課，並幫忙加入主畫面。
  • 「問教練」平常用內建答案，不用任何金鑰。沒有內建答案的問題，教練會自動把問題複製好，8 秒後帶您到 Gemini（可在設定改成 ChatGPT）。Gemini 不能自動填入問題，到了要按住輸入框選「貼上」，再按送出。提到匯款、投資的問題不會自動跳走，會留在畫面上請您打 165。
  • 想讓教練由 AI 回答：到「⚙ 常用設定 → AI 連線」填 API 金鑰（Gemini、OpenAI、Claude、OpenRouter）。金鑰只存在這支手機，費用由金鑰帳號負擔。
  • 「問教練」偵測到身分證或卡號會擋下來，不會送出；提到胸痛、中風會請長輩打 119，提到輕生會提供 1925。這只是關鍵字比對，不能取代家人關心。
  • 換手機前，到「⚙ 常用設定 → 資料備份」下載學習紀錄，再到新手機載入。
  • 用講的需要瀏覽器支援語音辨識；不支援時畫面會提示改用手機鍵盤的麥克風。朗讀的聲音由手機內建語音提供，各手機不同。

常用電話

  • 119 緊急救護、火災
  • 110 報案
  • 165 反詐騙諮詢專線
  • 1925 安心專線（24 小時）
  • 1966 長照專線
  • 1957 福利諮詢專線

使用警語

  • AI 可能說錯。健康、用藥、金錢、法律的事，請問醫師、藥師或專業人員。
  • 本工具的內容是教學參考，不是醫療、理財或法律建議。
  • 不要輸入身分證字號、銀行帳號、密碼。
  • ChatGPT、Gemini 等服務的畫面和收費會變動，請以官方說明為準。
  • 防詐題目的情境全部是虛構的，騙術也會一直變。不確定就打 165。
  • 學習紀錄只存在這台裝置的瀏覽器。清除瀏覽器資料後紀錄會消失。
  • 填了 API 金鑰後，問題會直接送到您選的 AI 服務，不會經過本站。
